# Colab AI + GitHub Starter

A small Python AI app run from Google Colab. It uses an AI API key for responses and the GitHub REST API to publish project files.

## Run it
Open the notebook in Google Colab, add `OPENAI_API_KEY` and `GITHUB_TOKEN` in Colab Secrets, enable notebook access, and run cells top to bottom.

## Security
Keep tokens in Colab Secrets. Never commit or share them.
